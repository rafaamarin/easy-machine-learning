# Datos del libro

El Corte 1 usa microdatos deterministas definidos dentro de cada laboratorio. Así, todos los ejemplos funcionan sin descargar datasets.

Los datasets grandes permanecen fuera de Git. Sus rutas se declaran solo en `configuracion/local.json`, creado a partir de `configuracion/local.ejemplo.json`.

Nunca copies aquí EuroSAT completo ni artefactos de entrenamiento.
